Themes

Same diagrams, your colours.

A theme recolours the surfaces, the text and Harpy's six responsibility colours. Pick one to see it on a flowchart and a sequence diagram, then load the build made for it.

Night

Every theme

Ten palettes

Each theme has a folder in dist/themes/ with the script and its base64, ready to embed without any request.

Dark and light

Follow the reader's system

A family pairs a dark and a light theme. Its build switches between them with the reader's system setting, the way Harpy's own night and parchment do.

    <!-- A whole family, following the system -->
<script src="…/dist/themes/nord/harpy.min.js"></script>

<!-- Or any build, with a theme per diagram -->
<harpy-diagram theme="gruvbox-dark">…</harpy-diagram>

<!-- Or a default for the page -->
<script> Harpy.configure({ theme: 'solarized' }) </script>
